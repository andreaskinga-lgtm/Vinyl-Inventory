# Discogs sync: claimed records are exempt from artist+title fallback matching

Discogs sync matches incoming releases to local records primarily by `discogsId`, falling back to normalized artist+title when no ID matches — this fallback existed to auto-link records added before a `discogsId` was known. Once multiple pressings of the same artist+title can coexist as separate records, this fallback becomes ambiguous and unsafe: it previously caused a record's `discogsId` to flip between two different Discogs releases on repeated syncs. We decided that a record with a non-null `discogsId` is permanently "claimed" and is never a candidate for fallback matching against a *different* incoming release, even if that release later disappears from the user's Discogs collection. If fallback matching finds zero unclaimed candidates, the incoming release is treated as new (so it's added alongside existing pressings); if it finds more than one unclaimed candidate, sync refuses to auto-match and requires the user to resolve it manually via the existing manual-match picker.
